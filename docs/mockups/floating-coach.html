웰니스 코치 시안

흔한 국내 쇼핑 앱 화면 구성(사진 배너 · 알약 바로가기 · 서비스 카드 · 가로 카드 · 순위)을 빌려 만들었습니다. 대표색은 파랑이고, 상품 자리에 식단 · 운동 · 챌린지를 넣었습니다.

화면별 대응

  • 사진 배너(위치 줄 · 알림 칩 · 큰 두 줄 제목 · 1/5) → 오늘 식단 추천 배너
  • 알약 바로가기(검색 · 재고찾기 · 점포찾기) → 검색 · 사진으로 기록 · 산책 코스 · 혈당
  • 서비스 카드(큰 카드 하나 + 작은 카드 둘) → 오늘 기록 + 어두운 AI 코치 카드 + 산책 코스
  • 두 줄 제목 + 가로 상품 카드(배지 · 색 태그 · 가격) → 저녁 추천(배지 · 태그 · kcal · 단백질)
  • 기획전 배너 + 세로 목록 → 진행중인 챌린지
  • 빨간 띠 배너 → 파란 띠(이번 주 근력)
  • 인기 상품 순위 → 이번 주 많이 한 운동
  • 흰 하단 바 + 가운데 둥근 사각 버튼(바코드) → 기록
  • 바코드 시트(제목 · 항상보기 스위치 · 밑줄 탭 · 하단 타일 2개) → AI 코치 시트(음성 답변 스위치 · 대화/오늘 요약/도움받기 · 요약 타일)
  • 이벤트 안내 목록(동그란 색 아이콘 줄) → 도움받기 탭의 상담 창구 목록

AI 코치 화면 (챗봇 레퍼런스 반영)

  • 바탕: 옅은 청회색 위에 그림자가 부드러운 흰 카드
  • 머리: 말꼬리 달린 파란 원형 아바타 + 이름 · 설명 + 동그란 아이콘 버튼(음성 답변, 닫기)
  • 탭: 밑줄 탭 대신 알약 모양 선택 버튼
  • 말풍선: 꼬리 달린 흰 말풍선(코치, 작은 아바타 옆) · 파란 말풍선(나), 입력 중 점 3개
  • 추천 질문: 아바타 + 알약 + 화살표 줄
  • 숫자 결과: 점선으로 나눈 흰 카드
  • 오늘 요약 · 도움받기: 글 왼쪽 + 동그란 아이콘 버튼 오른쪽 카드 줄
  • 입력: 파란 원형 마이크 + 알약 입력칸 + 원형 보내기, 맨 아래 홈 표시 막대

가져오지 않은 것

  • 초록색, 로고, 인물 · 상품 사진, 문구, 결제 · 상품 데이터
  • 사진은 GPT Image 2.6으로 새로 만든 7장(배너 · 음식 4 · 운동 2, docs/mockups/img/), 카드 · 목록 아이콘 18개도 GPT Image 2.6 3D 아이콘(img/icons/)이고, 하단 탭 · 닫기 · 보내기 같은 작은 UI 기호만 SVG입니다. 이모지는 쓰지 않습니다

움직이는 화면 (2026-11-18)

  • 근력 운동: 오늘 계획 → 운동 시작 → 세트마다 kg · 횟수 · 완료 → 운동 끝내기. 지난번 세트를 다 채운 종목은 증량을 제안해요
